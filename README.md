APTI DUDE is a browser-based aptitude and IQ practice platform designed to help learners sharpen reasoning, quantitative skills, and problem-solving speed in a clean, premium, distraction-free environment.

This project is a fully static single-page app with no build steps, no backend, and no dependency installation required. Just open the app in a browser and start practicing.

## Why this project?

Aptitude preparation often feels repetitive, cluttered, and disconnected from real learning progress. APTI DUDE solves that by combining:

- structured practice categories
- timed assessments
- progress tracking with local storage
- a polished user experience
- company-style aptitude practice modes

It is ideal for students, job seekers, and self-learners preparing for aptitude rounds, reasoning tests, and competitive exam-style problem solving.

## Features

- Progressive skill levels from Beginner to IQ Master
- Topic-based practice across multiple cognitive domains
- Company-style assessment families such as TCS and Infosys
- Timed quiz sessions with instant evaluation
- Dashboard tracking for tests, answers, best score, streak, and points
- Responsive interface for desktop and mobile screens
- Local browser persistence using `localStorage`
- No installation, build tools, or backend required
- Clean premium UI with warm colors, glass styling, and floating math-inspired effects

## Included practice domains

- Quantitative Aptitude
- Logical Reasoning
- Verbal Ability
- Analytical Thinking
- Technical Questions
- Mathematics
- Data Interpretation
- IQ Master

## How it works

1. Open `index.html` in your browser, or serve the project locally.
2. Choose a domain or assessment family.
3. Start a timed quiz and answer the questions.
4. Review performance and progress from the built-in dashboard.
5. Repeat sessions to improve accuracy, speed, and confidence.

## Quick start

### Option 1: Open directly

```bash
git clone https://github.com/saravanavel07/APTIDUDE.git
cd APTIDUDE
# Open index.html in a browser
```

### Option 2: Run a local server

```bash
cd APTIDUDE
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Tech stack

- HTML5

## Notes

- Progress is saved locally in the browser.
- This project is a front-end learning and practice app, not an official exam platform.
- Company names are used as practice categories and are not affiliated with actual recruitment assessments from those brands.
