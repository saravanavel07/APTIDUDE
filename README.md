# APTI DUDE

APTI DUDE is a single-page interactive IQ and aptitude practice platform.

## Features

- Premium white / sandal / gold UI
- Brain + detective-glass branding
- Animated mathematical particles
- Progressive levels from Beginner to IQ Master
- Quantitative aptitude
- Logical reasoning
- Verbal ability
- Analytical reasoning
- Mathematics
- Data interpretation
- Technical practice
- Company-style practice categories
- Timed assessment engine
- Question navigation
- Automatic scoring
- Master points and level progression
- Browser-local progress storage
- Profile settings
- Built-in terminal-style progress console
- Responsive desktop and mobile design

## Run locally

No build tools are required.

Open `index.html` directly in Chrome, Edge, Firefox, or another modern browser.

## GitHub Pages

Push the repository to GitHub and enable GitHub Pages from the repository settings. Select the `main` branch and the root folder.

## Important

The company names are used as practice-category labels. The project does not claim to reproduce or represent official current hiring assessments from those companies.
